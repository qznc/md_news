The Case for Progressive Enhancement: Why HTML-First Wins

Modern web development often favors complex JavaScript frameworks, but prioritizing the core language of the web can lead to massive gains in accessibility and user retention. As detailed by Alistair Davidson, shifting to an HTML-first design for a utility company's application process doubled their user completion rate overnight.

The problem began when a heavy React application was deployed, resulting in high failure rates due to loading spinners, excessive JavaScript states, and poor handling of data storage. Many users on old devices or unstable connections were effectively blocked from accessing essential services. By rebuilding the site with Astro, the developer ensured the application worked perfectly without JavaScript, treating scripts only as a layer of "progressive enhancement." Progressive enhancement is the practice of building a basic, functional version of a site first and then adding advanced features for browsers that can support them.

The new architecture relied on standard HTML form submissions and server-side redirects. Each step of the form wizard was its own page, ensuring that data was stored on the backend immediately. This prevented data loss, allowing some users to complete a form a month after starting it. To handle validation, a lightweight web component called validation-enhancer was used to improve the user experience while falling back to built-in browser validation if JavaScript failed.

This approach addresses a growing gap in the industry where some developers, often trained in bootcamps, treat the underlying HTML Living Standard as esoteric knowledge rather than the foundation. Discussions on Hacker News highlight a cultural shift where "fancy" front-ends are prioritized over reliability. The result is often a "React monstrosity" that works on a high-end iPhone but fails on a decade-old Android phone on a 3G connection.

Building for the lowest common denominator—such as a PlayStation Portable—ensures a service is truly available to everyone. When the foundation is robust HTML, the application remains functional regardless of the user's device or network quality.
