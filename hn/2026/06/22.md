# Shared CEF Runtime Architecture in Deno Desktop: A New Era of Cross-App Integration?

[The Deno team](https://docs.deno.com/runtime/desktop/) is introducing a compelling vision for desktop applications with their upcoming `deno desktop` feature, scheduled for Deno v2.9.0. This new capability aims to simplify turning web projects into standalone desktop apps while addressing common pain points in cross-platform development. However, one particularly intriguing aspect highlighted in community discussions revolves around a planned shared Chromium Embedded Framework (CEF) runtime, which could significantly impact how applications manage browser engine dependencies and binary sizes.

Unlike traditional approaches where each application bundles its entire web rendering engine, leading to large binaries, `deno desktop` proposes leveraging either the operating system's built-in webview or an optional bundled CEF backend. While the default webview approach ensures minimal binary footprints similar to Tauri, the bundled CEF option guarantees consistent rendering across macOS, Windows, and Linux platforms. Currently, every `deno desktop` app includes its own copy of CEF, resulting in substantial overhead. According to [community feedback](https://news.ycombinator.com/item?id=48626137), a future managed shared CEF runtime could dramatically reduce individual app sizes to just a few megabytes, akin to how desktop environments share system libraries today.

This architectural decision mirrors broader trends seen in competing frameworks like Electron, which famously bundles Chromium independently for each app, contributing to notoriously large binaries. By considering a shared CEF runtime, `deno desktop` potentially sidesteps the duplication problem while maintaining rendering consistency—a delicate balance that might reshape expectations for hybrid desktop applications. Yet questions remain about managing version discrepancies among apps requiring different CEF versions, echoing concerns raised in related discussions about achieving optimal tradeoffs in browser engine distribution.
