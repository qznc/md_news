# MD Tech News

A tool that automatically generates daily markdown articles summarizing the most important tech news from Hacker News.
It uses the official Hacker News API to fetch stories and an LLM to analyze, select, and summarize content into a readable markdown article.

## Features

- Fetches Hacker News frontpage in real-time
- Uses LLM to intelligently select relevant topics and URLs
- Fetches full article content for comprehensive summaries
- Generates markdown-formatted output with proper structure
- Saves dated archives automatically
- Two-step process ensures high-quality, focused content
