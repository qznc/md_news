# Stability Challenges and Solutions in Training Waveform‑Based Diffusion Models  

Training diffusion models directly on raw audio waveforms can produce high‑fidelity sound without hidden latent representations  
It eliminates the need for encoder‑decoder pipelines  
This simplifies the system architecture and reduces potential loss of detail  

However the raw‑waveform approach introduces several stability problems  
The signals are extremely high‑dimensional and contain many low‑energy components  
Training can become unstable after only a few thousand updates  
Gradient explosions and mode collapse are common when the model sees noisy inputs  

Recent research shows that simple preprocessing tricks can restore stable learning  
One effective method is amplitude lifting which rescales each signal independently to keep useful dynamic range  
By normalizing the source and target waveforms separately the model gains headroom for fine‑grained details  
Reference [WavFlow](https://arxiv.org/abs/2605.18749) demonstrates that amplitude lifting combined with flow‑matching training enables stable optimization in raw space  

Another practical solution is to use long overlapping windows during training  
Memory tokens are carried across windows so that the model retains context over long audio passages  
This avoids the need for separate VAE compression and allows direct waveform‑to‑waveform generation  
Reference [Stereo2Spatial v2](https://stereo2spatial.francislabounty.com) uses a conditional flow transformer with memory tokens and optional mix‑style conditioning to improve temporal alignment  

Validation experiments show that these techniques achieve competitive performance on benchmark tasks such as video‑to‑audio and text‑to‑audio synthesis  
The results prove that intermediate compression is not mandatory for high‑quality audio generation  
In summary the main challenges are high dimensionality, low‑energy noise, and training instability  
The proven solutions involve amplitude scaling, careful windowing, memory tokens, and flow‑matching updates  
These strategies together make raw‑waveform diffusion models both simpler and more scalable
