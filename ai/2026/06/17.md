# Breaking the Autoregressive Bottleneck: How Speculative Decoding Accelerates LLM Inference

Large language models face a significant performance bottleneck due to their slow, step-by-step generation process.
[Speculative decoding](https://paperswithcode.co/methods/speculative-decoding) has emerged as a leading method to overcome this limitation.
By using a small, fast model to guess several future tokens at once, it allows the system to bypass the slow, one-by-one generation cycle.
A larger model then verifies these guesses in parallel, ensuring that speed comes without losing quality.

The standard method of generating text, known as autoregressive decoding, requires tokens to be produced sequentially.
This process is poorly suited for modern hardware, which is designed to handle many tasks simultaneously.
Traditional speculative methods like the [EAGLE series](https://arxiv.org/abs/2503.01840) still rely on the draft model generating tokens one by one.
This sequential drafting limits the overall speedup that can be achieved.

A new approach called [DFlash](https://arxiv.org/abs/2602.06036) addresses this by using "block diffusion."
Instead of guessing tokens one at a time, it generates an entire block of tokens in a single parallel step.
To maintain high accuracy, DFlash uses "KV injection" to pass context directly from the large model to the small model.
This keeps the small model highly informed about the conversation, leading to more successful guesses and higher acceptance rates.

Implementing these techniques in real-world systems like the [SGLang engine](https://www.lmsys.org/blog/2026-06-15-next-generation-speculative-decoding-dflash-v2/) provides massive efficiency gains.
Benchmarks show that DFlash can achieve more than four times the throughput of standard models on specific coding datasets.
These speedups are vital for developers managing [real-time costs and autonomous agent loops](https://old.reddit.com/r/LLM/comments/1u88n87/architecture_question_enforcing_realtime_hard/).
Faster inference directly translates to lower operational expenses and more responsive AI applications.
